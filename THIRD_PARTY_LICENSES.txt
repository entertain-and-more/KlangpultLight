LEVEL 1 SBOM INVARIANT VALIDATION CONFIRMATION (Stand 2026-10-02):
- INV-LOCAL-01 (100% Local-First & Zero-Egress): PASS. Zero external network calls; audio, video, transcripts, and session plans remain local.
- INV-USER-02 (Unprivileged Execution & Non-Elevation): PASS. RunAsInvoker mode; standard user privileges without administrative elevation.
- INV-IPC-03 (Strict Loopback IPC Isolation): PASS. Recorder and Web Planer communicate strictly over 127.0.0.1 (ports 8767, 8769, 8770).
- INV-SAFE-04 (Safe Subprocess Boundaries): PASS. FFmpeg remuxing and video capture use explicit argument vectors (non-shell) and path traversal sanitization.
- INV-BUF-05 (Bounded Buffer & Audio Integrity): PASS. Multichannel audio buffers sanitize against NaN/Inf float samples and flush atomically to standard WAV containers.
- INV-STT-06 (Offline STT Degradation Boundary): PASS. Local faster-whisper transcription operates in an isolated worker thread; missing weights never stall recording or UI rendering.
- INV-STORE-07 (Caller-Controlled Session Storage): PASS. Session folders, event logs (events.jsonl), and recordings are owned and retained exclusively by the creator with zero auto-purge.
- INV-PLAT-08 (Cross-Platform Operating Parity): PASS. Architecture, protocol schemas (v1), and data models run consistently across Windows, Linux, and macOS.
- INV-SYNC-09 (Multi-Host & Sync Resilience): PASS. Hardened .gitignore ignoring sync conflict copies (*-conflict-*, *.sync-temp-*) and multi-agent locks (LOCK.*, *.lock).
- INV-SLA-10 (48h Response & 5-Day Triage SLA): PASS. Formal vulnerability response SLA under SECURITY.md with dedicated security contact channels.

ZERO-COPYLEFT & PERMISSIVE RUNTIME VERIFICATION:
- PySide6 is utilized strictly via dynamic linking under LGPL-3.0 (LGPLv3 Section 4 compliant).
- All core computational libraries (numpy, sounddevice, soundfile, websockets, jsonschema, mss) use permissive MIT/BSD-3-Clause licenses.
- Subprocess utilities (FFmpeg) are invoked out-of-process via standard IPC streams without linking.
