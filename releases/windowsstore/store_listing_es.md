## Descripción
Klangpult light es una estación de trabajo ligera y local para la producción de podcasts, grabación de audio y planificación de contenidos en Windows.

Ofrece grabación multipista para micrófonos USB, soundboard integrado para efectos y música, y un planificador web local para organizar escaletas y guiones de episodios sin depender de internet.

Características destacadas:
- Grabación multipista para micrófonos USB e interfaces
- Soundboard interactivo con atenuación automática (ducking)
- Planificador web local para guiones y notas de episodios
- 100% local y privado: sin sincronización en la nube requerida
