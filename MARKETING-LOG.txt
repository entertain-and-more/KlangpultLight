## 1. Executive Summary & Value Proposition
Klangpult light is a lightweight, local-first audio/video recording workstation and content planning suite designed for podcasters, voice artists, content creators, and media producers. Built with Python 3.10+ and PySide6 (Qt6) coupled with an offline HTML5/JS web planner, it unifies multichannel recording, system loopback audio capture, synchronized video muxing, live soundboard pads, teleprompter workflows, and local speech-to-text monitoring into a single privacy-first toolset.

Key Value Proposition:
- **100% Offline & Local-First**: Audio streams, video captures, transcripts, and episode scripts remain strictly on local disk in creator-owned workspaces. Zero third-party telemetry, zero cloud lock-in.
- **Decoupled Architecture**: High-performance PySide6 desktop recording core communicates with an agile web-based episode planner via local loopback sockets (`127.0.0.1:8767` / `:8769` / `:8770`), enabling dual-screen operation without cloud reliance.
- **Privacy-Guarded Speech-to-Text**: Local `faster-whisper` integration provides real-time transcription monitoring completely offline in an isolated background thread.
- **Non-Elevated Execution (`RunAsInvoker`)**: Runs strictly within standard user space without requiring administrator rights or elevated OS privileges.

## 2. Target Personas & Audiences

### [PERSONA-01] Podcast Creators, Voiceover Artists & Narrative Storytellers
- **Target Profile**: Solo podcasters, audio drama creators, voiceover professionals, and narrative interviewers seeking reliable multi-track recording.
- **Pain Points**: Cloud-based recording platforms with monthly fees, privacy leaks, upload timeouts, or unexpected latency; complex DAWs with overwhelming interfaces.
- **Value Proposition**: Streamlined multi-channel recording with dedicated mic and system loopback tracks, instant soundboard clip triggers, and integrated episode planning notes.
- **Key Workflows**: Launch `START_RECORDER.bat`, trigger sound effects via visual pads during live recordings, monitor speech levels, and automatically generate clean WAV containers.

### [PERSONA-02] Privacy-Conscious Streamers & Video Producers
- **Target Profile**: Content creators, software educators, and livestreamers who require local-first video and system audio capture without telemetry or cloud egress.
- **Pain Points**: High CPU overhead of heavy streaming suites when only quick local clips or tutorials are needed; risk of proprietary content syncing to third-party servers.
- **Value Proposition**: Synchronized screen video recording with FFmpeg remuxing, ultra-fast `mss` capture, and guaranteed 100% offline data sovereignty.
- **Key Workflows**: Capture desktop tutorial video and microphone audio synchronously, export cleanly muxed MP4 files, review sessions locally.

### [PERSONA-03] Event Planners, Content Strategists & Teleprompter Operators
- **Target Profile**: Media producers, webinar hosts, and editorial teams managing episode outlines, sponsor segments, and scripted speaking notes.
- **Pain Points**: Switching between disparate text editors, teleprompters, and recording tools during live takes; lost synchronization between script and recording time.
- **Value Proposition**: Built-in browser-based teleprompter (`planer/`) with smooth scrolling, timing indicators, and live bridge telemetry from the desktop recorder.
- **Key Workflows**: Draft episode rundown in the Planer, launch teleprompter on a second monitor, and trigger recording with real-time status feedback.

### [PERSONA-04] Modular Tool Integrators & Autonomous Multi-Agent Developers
- **Target Profile**: Software developers and AI agent engineers building local-first multimedia automation, podcast pipeline tools, or desktop workflows.
- **Pain Points**: Desktop media software lacks local loopback APIs or headless testing hooks; automation requires brittle GUI clicking.
- **Value Proposition**: Structured JSON and WebSocket IPC endpoints (`8767`, `:8769`, `:8770`), headless self-test modes (`$env:PODCAST_RECORDER_SELFTEST="1"`), and clean event-sourced logging (`events.jsonl`).
- **Key Workflows**: Automate media session verification via pytest, integrate transcription events into downstream summarization scripts, interact over loopback HTTP/WS.

### 10 Governance & Runtime Invariants
1. **INV-LOCAL-01 (100% Local-First & Zero-Egress):** Audio, video, transcriptions, and planning data remain strictly on the local machine. Zero analytics, telemetry, or outbound network calls.
2. **INV-USER-02 (Unprivileged Execution & Non-Elevation):** Operates under strict `RunAsInvoker` security without requiring administrator privileges or root access.
3. **INV-IPC-03 (Strict Loopback IPC Isolation):** IPC between PySide6 Recorder and HTTP Web Planer is bound exclusively to `127.0.0.1` (ports `8767`, `8769`, `8770`).
4. **INV-SAFE-04 (Safe Subprocess Boundaries):** FFmpeg remuxing and video capture subprocesses use explicit argument vectors (non-shell) and path traversal sanitization.
5. **INV-BUF-05 (Bounded Buffer & Audio Integrity):** Multichannel audio buffers sanitize against NaN/Inf float samples and flush atomically to standard WAV containers.
6. **INV-STT-06 (Offline STT Degradation Boundary):** Local `faster-whisper` transcription operates in an isolated worker thread with graceful fallback if weights are missing; never stalls real-time recording or UI rendering.
7. **INV-STORE-07 (Caller-Controlled Session Storage):** Session folders, event logs (`events.jsonl`), and recordings are owned and retained exclusively by the creator with zero auto-purge.
8. **INV-PLAT-08 (Cross-Platform Operating Parity):** Architecture, protocol schemas (`v1`), and data models run consistently across Windows, Linux, and macOS.
9. **INV-SYNC-09 (Multi-Host & Sync Resilience):** `.gitignore` rigorously ignores conflict copies (`*-conflict-*`, `*.sync-temp-*`) and multi-agent locks (`LOCK.*`, `*.lock`).
10. **INV-SLA-10 (48h Response & 5-Day Triage SLA):** Formal commitment to 48-hour response / 5-day triage SLA, validated by automated GitHub Actions CI matrices across Ubuntu, Windows, and macOS on Python 3.10, 3.11, 3.12, and 3.13.
